# Website assets

The five production images were recreated from the selected Midnight Studio template using the built-in imagegen tool. Their source, generation prompts and SHA-256 checksums are in zx/website-design-kit/2026-10-13/03-midnight-studio/production-assets/.

| Asset | Native dimensions | Placement |
| --- | --- | --- |
| hero-background.png | 1983 × 793 | Homepage background; right crop reused on login/mobile |
| builder-desktop.png | 1536 × 1024 | Builder hero photograph |
| enquiry-phone.png | 1774 × 887 | Enquiry follow-up card |
| quote-document.png | 1774 × 887 | Quote preparation card |
| booking-phone.png | 1774 × 887 | Booking reminders card |

The source and publish copies preserve the original PNG bytes. No resizing, format conversion or recompression was applied.

xasis-symbol.svg renders ZX's supplied faceted lavender symbol and violet orbit as native vector paths for crisp header, footer and favicon use.

space-grotesk.ttf and inter.ttf came from the official Google Fonts repository. Their SIL Open Font License files are included as SpaceGrotesk-OFL.txt and Inter-OFL.txt.

Earlier bridge and Manrope files remain historical assets in Team HQ. They are not used by the current pages.
